## Descrição do projeto 

<p align="justify">
  <b>Oracle Next Education - A tecnologia é para todos:</b> O ONE é um programa de educação e empregabilidade com objetivo social de capacitar pessoas em tecnologia e conectá-las com o mercado de trabalho por meio de empresas parceiras. O curso é 100% online e totalmente gratuito, feito para quem não teve acesso à educação de qualidade e deseja transformar a sua realidade social. Esta formação faz parte do programa ONE, parceria de Alura + Oracle. Saiba mais em <a href="https://www.oracle.com/br/education/oracle-next-education/">Oracle Next Education</a>.
  <br><br>
  Neste desafio, o objetivo principal foi assumir o papel de assistente de análise de dados na equipe de Data Science da <b>Telecom X</b>, uma empresa de telecomunicações que vem sofrendo com um alto índice de evasão de clientes (Churn). 
  <br><br>
  Para descobrir o porquê disso estar acontecendo, foi realizado um processo completo de ETL, começando pela extração dos dados da empresa através de uma API armazenada no GitHub. Em seguida, os dados foram transformados, limpos e tratados para a realização de uma profunda Análise Exploratória de Dados (EDA). O desafio culminou em um relatório embasado em dados visuais para identificar padrões de comportamento dos clientes, permitindo que colegas mais experientes criem modelos preditivos futuros e ajudando a empresa a reduzir sua taxa de evasão.
</p>

## O que foi praticado :dart:

:heavy_check_mark: Extração de dados consumindo uma API em formato JSON.
<br>
:heavy_check_mark: Processo de Transformação e Limpeza de dados (ETL), incluindo o achatamento (flattening) de estruturas aninhadas utilizando a biblioteca **Pandas**.
<br>
:heavy_check_mark: Criação de visualizações de dados claras e eficientes com as bibliotecas **Matplotlib** e **Seaborn** para identificar padrões de evasão.
<br>
:heavy_check_mark: Análise Exploratória de Dados (EDA) focada em métricas de negócios, como tipos de contrato, métodos de pagamento, faixa etária e tempo de permanência.
<br>
:heavy_check_mark: Elaboração de relatórios e tomada de decisão baseada em dados (Data-Driven Decision Making).

## Como rodar a aplicação :arrow_forward:

1. No seu terminal, faça o clone do projeto: 

```bash
git clone [https://github.com/frneide/challenge-TelecomX-1-ALURA](https://github.com/frneide/challenge-TelecomX-1-ALURA)
```

2. Certifique-se de ter o Python instalado na sua máquina, assim como o Jupyter Notebook (ou utilize o Google Colab).

3. Instale as bibliotecas necessárias para rodar as análises:
```bash
pip install pandas matplotlib seaborn requests
```

4. Abra o arquivo **".ipynb"** (notebook) correspondente ao projeto.

5. Execute as células sequencialmente para visualizar a extração da API, os tratamentos de dados e a geração dos gráficos que embasam o relatório final!
